# EasyInput V0.1 · 二次开发版

> **在 EasyInput V2.0 的基础上，把「语音输入键盘」扩展成一台完整的桌面语音工作站。**
>
> 上游产品：[easyinput.pro](https://easyinput.pro/) · EasyInput V2.0（硬件）+ EasyInput App（官方软件）
> 本仓库：**我们的二次开发** —— 自研电脑端软件 + 自研固件，Windows 免安装

## 一、先说清楚：EasyInput 是什么（上游产品）

**EasyInput 是一款「键盘 + App」的语音输入产品**，官方口号 **"让输入跟上想法"**。

它不是普通键盘 —— 是一块**带麦克风、八个按键、一个旋钮、五颗状态灯**的桌面硬件，
配合电脑端 App，让你**用说话代替打字**：

| 上游产品的核心能力 | 说明 |
|---|---|
| **说话即输入** | 对着键盘说话 → 转成文字 → **直接写进当前光标处**（聊天框/文档/表单都行） |
| **八个可编程按键** | 语音输入、回车、语音编辑、退格、全选/复制/粘贴/撤销 —— 都能在 App 里改 |
| **可按压旋钮** | 旋转 = 页面上下滚动；按一下 = 切成左右滚动；长按 3 秒 = 临时设置窗口 |
| **五颗状态灯** | 配合 AI 编程助手显示"执行中 / 需确认 / 已完成 / 失败" |
| **语音编辑** | 选中一段文字 → 按语音编辑键说要求（"改得更简洁""翻译成英文"）→ 改写选中内容 |
| **高度可玩** | 键帽可换、轴体热插拔（免焊接）、旋钮帽可换；社区共创外壳与玩法 |
| **门槛低** | 不接键盘也能用电脑麦克风在 App 里开口输入 |

**三种连接各管什么**（上游定义，最容易误会的点）：

| 通道 | 作用 | 限制 |
|---|---|---|
| **USB** | 触发按键功能、读写开发板设置、同步开机音效 | 必须是**数据线**，充电线无效 |
| **蓝牙** | 无线触发按键 | 系统显示"已连接" ≠ App 设置通道可用 |
| **Wi-Fi** | 传送**开发板麦克风**的声音 | 开发板**仅支持 2.4GHz** |

> 📖 上游资料：[官网](https://easyinput.pro/) · [使用说明](https://easyinput.pro/manual/) ·
> [固件基线仓库](https://github.com/CY-CHENYUE/easy-input-maker) · [开发板知识库](https://github.com/CY-CHENYUE/easyinput-board-cy)
>
> ⚠️ 开发板是**输入开发板，不是成品键盘**（上游明确说明）。

## 二、我们做了什么（二次开发）

我们在上游基础上重写了**电脑端软件**并扩展了**固件能力**，把它从"语音输入工具"做成
**能本地跑、能联网答、能自己扩展的语音工作站**：

| 能力 | 上游 | **我们（V0.1）** |
|---|---|---|
| 语音识别引擎 | 云端为主 | **本地 whisper 离线识别**（免费、断网可用）+ 任意 OpenAI 兼容接口 |
| 语音编辑 | 依赖云端服务 | **自研管道**：抓选区 → 大模型改写 → 替换，带**意图护栏**（口述内容不会被误改） |
| **语音提问** | — | 🆕 按住键直接问 → 答案打进光标（**软件自己联网**，免 Key） |
| **联网检索** | — | 🆕 自动换源（搜狗→360→Bing）+ **抓网页正文** + 行情/天气实时值 |
| **宏系统** | — | 🆕 一键触发一串动作（按键/延时/文本/打开程序或网址） |
| **灯效** | 状态灯 | 🆕 **频谱 / 呼吸 / 场景色**（音频驱动） |
| **播放器** | 开机音效 | 🆕 任意音频上板播放 + 板载节拍器 |
| **模块系统** | — | 🆕 自定义按键面板（JSON 定义 + AI 生成），支持多页/旋钮翻页 |
| 软件形态 | 官方 App | **免安装 EXE**（绿色版，配置随身带） |

**技术栈**：电脑端 Python（pywebview 网页界面）· 固件 ESP-IDF（ESP32-S3）· 本地识别 faster-whisper

## 三、快速开始

1. **解压**到任意目录（**整个文件夹一起**，`EasyInput.exe` 要读同目录的 `_internal`）
2. 双击 **`EasyInput.exe`**
3. 设置页配一次 **STT 引擎**：
   - 想离线 → 选"本地 whisper"（首次自动下模型，见下）
   - 想用云 → 选"OpenAI 兼容"填接口

> ⚠️ **前置依赖**：界面用网页渲染，需要 **WebView2 Runtime**。
> Win11 通常自带；没有会弹提示，照它给的命令装：`winget install Microsoft.EdgeWebView2Runtime`

**没有硬件也能用** —— 转录、宏、划词编辑都可用，只是没有实体按键触发。

## 四、文件说明

```
easyinputV0.1/
├── EasyInput.exe                     主程序（双击运行）
├── _internal/                        程序本体（依赖库 + 界面 + 驱动 DLL，勿删勿移）
├── firmware/
│   └── easyinput_fw.bin              ESP32-S3 固件（软件内"固件更新"直接选它烧录）
├── models-faster-whisper-small.zip   本地识别模型（427MB，见第五节）
└── README.md                         本文件
```

运行时在同目录自动生成（**可随身带，删掉即恢复默认**）：

```
config.json            你的配置（含 API Key —— 只存本机，不会被上传）
macros.json            宏配置
models/                本地识别模型（解压上面的 zip 到这里）
last_recording.wav     最近一次录音（排查用）
app_log.txt            运行日志
```

### ✅ 设置会保留（关掉再开还在）

配置**写在 EXE 同目录**，所以：

| 情况 | 配置在哪 | 会保留吗 |
|---|---|---|
| 解压到普通目录（桌面/D盘/U盘） | 同目录 `config.json` | ✅ 保留，**可整个文件夹拷走** |
| 放在 Program Files 等**受保护目录** | 自动回退到 `%APPDATA%\EasyInput\config.json` | ✅ 保留（换个位置放也一样） |
| **直接在 zip 里双击运行**（没解压） | Windows 临时目录 | ❌ **关掉就丢** |

> ⚠️ 所以：**先解压再运行**（右键 zip → 全部解压）。这是唯一会让设置丢失的情况。

## 五、离线语音识别（本地 whisper）

**会自己下载**，不用手动准备。国内直连 huggingface.co 很慢/不通，所以代码**默认走 `hf-mirror.com` 镜像**。

### 方式 A：自动下载（需网络）
设置 → STT 引擎 → 选 **本地 whisper** → 模型 `small` → 第一次说话时自动下载（**约 460 MB**）→ 之后**完全离线**

### 方式 B：用附带的 zip（无网/网慢）
把 `models-faster-whisper-small.zip` **解压到与 `EasyInput.exe` 同级**（得到 `models/` 目录）→ 重启即可

### 方式 C：不用本地识别
选 **OpenAI 兼容**，填任意兼容接口（OpenAI / Groq / 硅基流动 / 阿里百炼…）

> 模型大小：`tiny`（最快）/ `base` / `small`（默认，平衡）/ `medium`（最准最慢）

## 六、硬件与烧录

| 项 | 参数 |
|---|---|
| 主控 | ESP32-S3（双 USB CDC：命令口 + 音频流口） |
| 按键 | S1~S8 = GPIO `2, 47, 38, 41, 1, 6, 7, 48`（低有效） |
| 旋钮 | A/B/按压 = GPIO `17 / 16 / 18` |
| 灯 | 5 颗 WS2812 串联（GPIO12） |
| 麦克风 / 扬声器 | `9/10/11` · `14/13/15`（共享电源 GPIO8） |
| 连接 | USB / Wi-Fi(2.4G) / BLE 三通道 |

**烧录**（我们的软件内置 esptool，只烧 app 分区）：
1. 板子进下载模式：**保持开机 → 短按并松开 BOOT** → 等电脑出现 ESP32-S3 下载端口
2. 软件 → 固件更新 → 选 `firmware/easyinput_fw.bin` → 烧录
3. **拔插 USB** 重启板子（下载模式下 esptool 复位无效）

> 上游开发板细节（原理图/PCB/pinout）见 [easyinput-board-cy](https://github.com/CY-CHENYUE/easyinput-board-cy)

## 七、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击没反应 | 看同目录 `easyinput_exe_error.log`；多半缺 WebView2 Runtime |
| 界面全白 | 缺 WebView2 Runtime（弹窗里有安装命令） |
| 提示"已在运行" | 单实例保护（防两个进程抢串口）—— 看任务栏 |
| 本地识别下不动 | 用方式 B（附带 zip）；或换在线 STT |
| 划词编辑没反应 | 该应用不支持 UIA 抓选区（终端类常见）→ 自动回落成普通转录 |
| 微信/QQ 里多行被直接发送 | 回车被当成发送键；建议回填方式改"粘贴" |
| 识别了但没落进输入框 | 杀毒/权限拦截 —— 把 `EasyInput.exe` 加入信任列表；管理员窗口无法注入 |
