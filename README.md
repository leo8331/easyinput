# EasyInput V0.1

> 一个把 **实体键盘底座** 变成语音输入 / AI 编辑入口的桌面工具。
> 按住板子上的键说话 → 转文字 → 直接打进光标处；选中一段文字再说话 → AI 改写后**替换选区**。

**当前版本：V0.1**（2026-09-18）· 平台：Windows 10/11 x64 · 免安装

---

## 它解决什么问题

| 场景 | 怎么做 |
|---|---|
| 不想打字 | 按住录音键说话 → 文字直接出现在光标处（本地识别，离线免费） |
| 改一段文字 | **选中它** → 按住录音键说"翻译成英文 / 帮我写得专业一点" → **选区被替换**（Ctrl+Z 可还原） |
| 问点东西 | 按住**提问键**直接问"纳斯达克现在多少点" → 答案打进光标（软件自己联网查，免 Key） |
| 快捷操作 | 宏：一键打开程序 / 网址、输入常用语、组合键 |

## 快速开始（3 步）

1. **解压**到任意目录（**整个文件夹一起**，`EasyInput.exe` 要读同目录的 `_internal`）。
2. 双击 **`EasyInput.exe`**。
3. 按界面提示配一次 **STT 引擎**（想离线就选"本地 whisper"，首次会自动下载模型，见下）。

> ⚠️ **前置依赖**：界面用网页渲染，需要 **WebView2 Runtime**。
> Win11 通常自带；没有的话软件会弹提示，照它给的命令装：
> `winget install Microsoft.EdgeWebView2Runtime`

## 离线语音识别（本地 whisper）

**会自己下载**，不用手动准备。但国内直连 huggingface.co 很慢/不通，所以：

### 方式 A：让它自动下（推荐，需网络）
1. 界面 → 设置 → **STT 引擎** → 选 **本地 whisper** → 模型选 `small`
2. 第一次说话时会自动下载（**约 460 MB**，走 `hf-mirror.com` 镜像，代码已内置）
3. 下完存到 `models/`，之后**完全离线**，断网也能用

### 方式 B：用附带的 zip（无网/网慢时）
1. 把 `models-faster-whisper-small.zip` **解压到与 `EasyInput.exe` 同级**（会得到 `models/` 目录）
2. 目录结构必须是：
   ```
   models/hub/models--Systran--faster-whisper-small/snapshots/<一串哈希>/model.bin
   ```
   （zip 里已经是这个结构，直接解压即可）
3. 重启软件 → 选"本地 whisper" → 直接可用

### 方式 C：不用本地识别
选 **OpenAI 兼容**，填任意兼容接口（OpenAI / Groq / 硅基流动 / 阿里百炼…），无需下载模型。

> 换模型大小：`tiny`（最快、准确率低）/ `base` / `small`（默认，平衡）/ `medium`（最准、最慢）。

## 硬件（可选）

不接硬件也能用（转录、宏、划词编辑都可用），只是没有实体按键触发。

| 项 | 说明 |
|---|---|
| 主控 | ESP32-S3（双 USB CDC：命令口 + 音频流口） |
| 按键 | S1~S8 + 旋钮（左/右旋 + 按下） |
| 连接 | USB / WiFi(TCP) / BLE 三通道 |
| 固件 | `firmware/easyinput_fw.bin`（软件内"固件更新"烧录，只烧 app 分区 `0x10000`） |

**烧录**：板子进下载模式（USB 插上后按住 BOOT 再按 RST）→ 软件识别到 `PID 1001` → 选 bin → 烧录 → **拔插 USB** 重启。

## 功能一览

- **语音转录**：板子录音 → 本地/在线 STT → 打字注入或进历史
- **划词 AI 编辑**：选中文本 + 语音指令 → 大模型改写 → **替换选区**；有意图护栏（你口述内容不会被当成指令改文）
- **语音提问键**：不选任何东西直接问 → 答案打字；**软件自己联网**（免 Key，自动换源 + 抓网页正文 + 行情/天气实时值）
- **宏系统**：按键触发一串动作（按键/延时/文本/滚轮/打开程序或网址）
- **灯效**：频谱 / 呼吸 / 场景色；模块灯指示
- **播放器**：把音频传到板子喇叭播放；节拍器
- **模块系统**：自定义按键面板（JSON 定义 + AI 生成）

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击没反应 | 看同目录 `easyinput_exe_error.log`；多半是缺 WebView2 Runtime |
| 界面全白 | 缺 WebView2 Runtime（弹窗里有安装命令） |
| 提示"已在运行" | 单实例保护（防两个进程抢串口）—— 看任务栏 |
| 本地识别下不动 | 走方式 B（用附带 zip）；或换在线 STT |
| 划词编辑没反应 | 该应用不支持 UIA 抓选区（终端类常见）→ 会自动退回"没抓到选区"，请用普通转录 |
| 微信/QQ 里多行输出被直接发送 | 回车被当成发送键；建议在设置里把回填方式改为"粘贴" |
| 版本号显示"（源码）" | 你在用源码运行，不是 EXE —— 正常 |
